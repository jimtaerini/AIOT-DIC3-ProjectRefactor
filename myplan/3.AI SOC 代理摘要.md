# AI SOC 代理摘要

## 摘要（約 500 字）

### A. Attention Getter（動機與引題）

臺灣關鍵基礎設施正面臨高強度且持續的網路威脅。國安局指出，2025 年中共對我國政府、能源、醫療、交通、金融與科學園區等九大類關鍵基礎設施的日均網路侵擾達 263 萬次，較 2024 年成長 6%，其中能源、緊急救援與醫院增幅最顯著。同時，資安事件若未能即時辨識與處置，將造成營運中斷、資料外洩與國安風險。因此，資安維運中心（SOC）能否快速、正確地分級告警，已成為降低損害的關鍵。（來源：nsb+1）

### B. But（挑戰與研究缺口）

然而，SOC 普遍面臨大量誤報、重複告警與分析師疲勞問題，導致真實攻擊可能被延後調查或誤判為良性事件。現有機器學習方法雖能依歷史資料預測告警類別，卻缺乏攻擊鏈與資產脈絡；大型語言模型（LLM）雖具推理能力，但在證據檢索不足時容易過早結案。最新 Alert-Bench 研究顯示，五種 LLM Agent 推理策略在 1,247 則多階段攻擊告警中，至少漏判 40.4% 的攻擊相關告警。此外，過度自動化也可能造成分析師自動化自滿，削弱人類監督與問責能力。（來源：arxiv）

### C. Cure（提出的解決方案）

本研究提出一個 AI SOC Analyst Agent，整合機器學習、資安領域知識與 LLM 推理，提供有依據、可解釋且具備主動升級機制的告警分級系統。系統並非追求全面自動結案，而是在證據不足、資產關鍵性高或判斷不確定時，主動將告警升級給人類分析師，以兼顧效率與安全。

### D. Development（方法設計）

本研究以 Gradient Boosted Trees（GBDT）預測事件屬於 True Positive（TP）、Benign Positive（BP）或 False Positive（FP）的機率，並以 SHAP 解釋關鍵特徵貢獻。接著，系統透過 Chroma 向量資料庫檢索 MITRE ATT&CK 攻擊技術與 NIST SP 800-61 Rev. 3 事件回應流程，補足 ML 模型缺乏的攻擊鏈與標準作業知識。最後，ReAct LLM 依「思考—行動—觀察」流程進行證據蒐集與推理，並由證據融合模組決定是否自動分級或升級處理。

### E. Experiments（實驗規劃）

實驗將採用 Microsoft GUIDE 與 ExCyTIn-Bench 資料集。GUIDE 包含超過 1,300 萬筆證據、160 萬筆告警與 100 萬起由客戶資安分析師標註的事件，涵蓋 TP、BP 與 FP 三類分級標籤，並建議以 Macro-F1 作為主要評估指標。ExCyTIn-Bench 則可評估 Agent 進行多跳日誌檢索與威脅調查的能力。本研究將比較多數類別、歷史誤報率規則、純 GBDT、純 LLM 與混合式 Agent 等基線，評估 Macro-F1、TP 漏判率、FP 壓制率與人工升級率。（來源：kaggle+1）

### F. Findings／Expected Outcomes（預期成果）

預期本研究能證明，相較於純 ML 或純 LLM 方法，混合式 AI SOC Analyst Agent 可在降低 TP 漏判率的同時，控制誤報與人工複核成本。研究亦將量化「自動化程度」與「人工升級率」之間的取捨關係，並產出包含原始告警、ATT&CK 對應、SHAP 解釋、檢索證據、推理過程與處置建議的可審計報告。最終，本研究期望為 SOC 提供一套可重現、可解釋且符合人機協作原則的智慧告警分級框架。（來源：arxiv+1）

## 可補充的學術定位

本研究的學術價值在於將 GBDT 的統計判斷、SHAP 的可解釋性、ATT&CK／NIST 的領域知識，以及 LLM 的動態推理整合為一個可審計決策流程。相較於僅依賴 LLM 的 SOC Agent，本研究強調「證據優先、保守升級、人機協作」，回應了目前 LLM 在告警調查中漏判率高、容易過早結案的問題。（來源：arxiv）

GUIDE 提供大規模真實事件與三類分級標籤，適合作為分類與處置建議的主要評估基準；ExCyTIn-Bench 則補足多跳調查與跨日誌關聯能力的評估需求。因此，本研究的預期貢獻不僅是提升分類準確率，更是建立一套可重現、可解釋且具安全邊界的 SOC AI 評估與部署框架。
